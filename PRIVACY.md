# Privacy Policy

Image Tiler processes input JPEG and PNG files only inside the Dify plugin runtime in order to create JPEG overview and tile files.

The plugin does not transmit images, manifests, filenames, or metadata to external services. It does not use analytics, telemetry, cookies, credentials, or persistent storage. Input and output files are handled by Dify according to the host workspace's file retention and access policies.

Contact: https://github.com/KouuShin/image-tiler
