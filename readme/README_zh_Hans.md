# 图片切片

这是一个离线 Dify 工具插件：输入 JPEG 或 PNG 图片，输出整图 overview、带重叠的局部 JPEG 切片，以及来源清单。

## 安装与使用

1. 从仓库下载最新的 `.difypkg` 文件。
2. 在 Dify 中打开“插件 → 安装插件 → 本地插件包”，选择下载的文件。
3. 在工作流中添加“图片切片”工具节点，将 JPEG 或 PNG 图片数组连接到 `images`。
4. 按需设置行数、列数、重叠比例、JPEG 质量和是否输出整图。

默认设置下，每张输入图片会生成一张整图和九张带重叠的局部切片，并返回记录来源与坐标的清单。
